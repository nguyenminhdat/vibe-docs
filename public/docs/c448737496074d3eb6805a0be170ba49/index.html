Start small. Make it yours.

This page is a working HTML template: clear typography, a single content column and responsive spacing. Download it from the library, edit the text and publish it with a new slug.

A useful structure

  1. Give the document a clear title.
  2. Lead with the key idea.
  3. Add evidence, examples or instructions.
  4. Include relevant sources and a date.

Your next step

vdocs publish ./my-document.html --public --slug my-document --category Documents
