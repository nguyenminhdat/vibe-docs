VIBE DOCS / PUBLIC DEMO

The one-command publishing guide

From local HTML to a stable, shareable URL. A practical walkthrough.

1. Connect your workspace

gh repo clone nguyenminhdat/vibe-docs
cd vibe-docs
npm link

2. Publish an HTML file

vdocs publish ./file.html --public

Relative stylesheets, images and scripts are collected with the file. For dynamically loaded assets, use a dedicated folder with index.html.

3. Add a title and category

vdocs publish ./report --public --slug report --title "Public report" --category Reports

4. Update at the same URL

Run the same command with the same slug. GitHub Actions rebuilds the library and the document stays at the original link.

Review before sharing

Only publish files cleared for public distribution. Inspect every included asset. The automated scanner checks common patterns and does not replace your review.
