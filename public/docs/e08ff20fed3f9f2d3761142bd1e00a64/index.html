VIBE DOCS / PUBLIC DEMO

Your ideas.
A link away.

Vibe Docs turns your HTML files into documents anyone can open, share and download. No database. No backend. Just your files and GitHub Pages.

Publish a document

vdocs publish ./file.html --public

Publish a folder with an index.html to include CSS, JavaScript, images and fonts. Local assets referenced by a single HTML file are collected automatically.

Update without breaking links

Publish again with the same filename or explicit --slug. The document stays at the same URL.

Keep it public, keep it intentional

This repository is public. Publish only content you own and have cleared for public sharing. The CLI checks common secret patterns, but cannot determine whether a document is approved for sharing.
